The mini project (Experiments 11–15) is the **Household Electricity Consumption Prediction System** from the project proposal. Its phases must be run in order, because each phase reads the previous phase's outputs.

## Setup
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
On macOS/Linux, activate with `source venv/bin/activate` instead.

## Run everything
```bash
python run_all.py
```
To run only some experiments, list their numbers:
```bash
python run_all.py 4 9
```
There is no user interface. The REST APIs required by the syllabus (Experiments 6, 7, 8, 10, 14, 15, 19, 20) return JSON, and `run_all.py` tests them with Flask's test client, so no server is left running.

## Notes
- **Docker** (Experiments 6, 10, 14, 15, 20) needs Docker Desktop running. The Python code in those experiments also runs without Docker.
- **Continuous integration:** [`.github/workflows/ci.yml`](.github/workflows/ci.yml) runs all 20 experiments on every push. The plots, metrics and reports it generates can be downloaded as the `experiment-outputs` artifact from each run in the Actions tab. The workflow files inside Experiments 5, 8 and 15 are per-project examples. GitHub only runs workflows from the repository root, so copy one there if a project becomes its own repository.
- **Datasets:** Iris, House Price and Titanic are your lab datasets. California Housing (scikit-learn), Wine and Breast Cancer ship with scikit-learn. The household power, student, fake news and employee datasets are generated by the scripts so everything runs offline. The docstring at the top of each data script explains how to swap in the real public dataset.
- Tested with Python 3.14, scikit-learn 1.9, pandas 3.0, MLflow 3.17 and DVC 3.67.
